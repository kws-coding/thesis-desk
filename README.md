# Thesis Desk

Thesis Desk is an AI-assisted equity research tool for a single user. You give it an investment thesis, refine it together with an LLM, and it surfaces stocks that fit, along with bull and bear cases, fair value ranges, entry prices, financial health metrics, red flags, and push alerts for ongoing monitoring. All financial math is deterministic code; the LLM only reads text and writes cited summaries.

**Disclaimer:** This is a personal research tool, not investment advice. It does not trade and does not connect to any brokerage. All outputs are model results based on stated assumptions.
